# Bandit Wargame Notes

My notes on [OverTheWire Bandit](https://overthewire.org/wargames/bandit/), a free practice game that teaches Linux and security basics one level at a time.

**These notes contain no passwords or step-by-step solutions**, because OverTheWire asks players not to publish them. Each file covers the goal, the idea behind the level, and what I learned.
