# Bandit Level 1: a file named with a dash

**Status:** Completed. Draft notes; my own details are still to be added.

**Idea:** many commands treat a name that starts with a dash as an option, not as a file, so you have to tell the shell it is a path.

- **Goal:** read a file in the home folder whose name is just a dash.
- **Concepts:** how the shell reads arguments, and how to refer to a file by its path.
- **My notes:** Understanding how Linux interprets filenames.
